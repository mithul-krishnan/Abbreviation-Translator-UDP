UDP Abbreviation Translator

The UDP Abbreviation Translator is a client-server application developed in C using UDP socket programming. It translates common internet slang, chat abbreviations, and texting acronyms into their full meanings. The application uses IPv4 UDP sockets to enable communication between the client and server over port 8080. The client allows users to enter sentences, which are sent to the server using sendto(). The server receives messages using recvfrom(), checks the words against a predefined abbreviation dictionary, replaces recognized abbreviations with their full forms, and sends the translated sentence back to the client. The application supports case-insensitive matching, multiple requests, and preserves unrecognized words. It is developed for Ubuntu/Linux using the C programming language, GCC compiler, and standard libraries such as stdio.h, string.h, strings.h, unistd.h, arpa/inet.h, and sys/socket.h. The project demonstrates fundamental networking concepts, including socket creation, binding, data transmission, reception, and client-server communication. It can be compiled using GCC and executed through two separate terminals, one for the server and another for the client. The abbreviation dictionary can be expanded by adding new entries to the server code. Future enhancements could include a larger dictionary, punctuation handling, context-aware translation, external dictionary files, graphical user interface, and support for multiple clients. The project provides practical experience in C programming, UDP networking, string manipulation, Linux development, and GitHub version control.
